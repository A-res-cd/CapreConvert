# Checks

Phase 1: invalid configuration, workspace ownership, lifecycle, health, local assets.
Phase 2: deterministic decoder double for exact rendering parameters, transfer, orientation,
dimensions, atomic publication, corrupt input and unchanged originals; real fixtures optional.
Phase 3: nested/mixed/multiple ZIPs, path/link/encryption/bomb rejection, CRC, collisions.
Phase 4: owned upload/job API, idempotency, spawned invalid worker, scheduling/cancel/restart.
Phase 5: Playwright desktop/mobile, picker/settings, flow/error, refresh, downloads and no
external network. Successful UI output uses a clearly identified conversion double.
Phase 6: memory/disk admission, timeout/crash, cleanup, Host/Origin/CSRF and foreign IDs.
Phase 7: build and smoke launch on Windows; separately benchmark real packaged conversion
with provenance-documented private CR3 inputs. The standardized camera/mode fixture matrix
is a distinct acceptance gate. See MEMORY_OPTIMIZATION.md for the executed private results.
Phase 8: run full suite; record exact commands, platforms, decoder versions and blockers.

No fake bytes count as real decoder compatibility. No fixtures with unclear redistribution
rights are downloaded. Clean-machine, physical iPhone/Android, camera color/resource tests
require appropriate external hardware and provenance-documented samples.

Preview extension: verify landscape/portrait bounds, no upscaling or source modification,
capture/GPS stripping, ICC/orientation, atomic derivative pairs and failure fallback. Verify
preview/selected-export ownership and CSRF, exact selected full-JPG ZIP bytes, cache reuse,
active-download eviction protection, failure reservation cleanup and restart preservation.
Browser checks cover thumbnail/large viewing, per-photo and bulk selection, single JPG vs
selected ZIP downloads, refresh, cross-page selection, mobile keyboard/touch and layout.
